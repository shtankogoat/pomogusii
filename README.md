# ПомогусИИ — лендинг для Tilda

- `index.html` — готовая страница для предпросмотра (открыть двойным кликом в браузере).
- `tilda/` — та же страница, разбитая на блоки. Именно их вставляем в Tilda.
- `build.py` — пересобирает `index.html` из блоков (`python build.py`). Нужен только для правок вне Tilda.

## Как перенести на Tilda

1. **Настройки страницы** → Цвет фона: `#0b0705`.
2. Для каждого файла из папки `tilda/` по порядку (00, 01, 02 … 15):
   - Добавить блок → «Другое» → **T123 «Вставка HTML-кода»**;
   - открыть «Контент», вставить **всё** содержимое файла, сохранить;
   - в «Настройках» блока выставить отступы сверху и снизу **0**.
3. Блок `00-styles.html` должен быть **первым**: в нём всё оформление (цвета, шрифты, адаптив). Не удаляйте его.
   Блок `15-effects.html` ставится **последним**: живой фон, курсор-круг, анимации и FAQ «один открытый вопрос». Если его удалить, сайт работает, просто без эффектов.
4. **Попап оплаты.** Все кнопки «Вступить / Получить доступ» ведут на `#popup:tarif1`.
   Перенесите со старой страницы блок-попап **T868** с виджетом GetCourse (в его настройках ссылка-хук `#popup:tarif1`),
   либо создайте новый T868 и вставьте в него:
   ```html
   <script id="47ba71c13b415f85f08128b4062f6260dfce9c83" src="https://pomogusii.getcourse.ru/pl/lite/widget/script?id=1598811"></script>
   ```
5. Опубликовать. Вид в редакторе Tilda может отличаться — проверяйте на опубликованной странице.

## Как редактировать самостоятельно

Откройте нужный блок → «Контент». Меняйте только текст **между** тегами, сами теги `<…>` не трогайте.

| Что поменять | Где |
|---|---|
| Цена, скидка | `11-tariff.html` — строки `5 000 ₽`, `1 990 ₽`, `−60%` |
| Вопросы и ответы | `12-faq.html` — чтобы добавить вопрос, скопируйте целиком кусок от `<details` до `</details>` |
| Фото автора | загрузите фото в Tilda (Настройки сайта → Файлы или любой блок с картинкой), скопируйте ссылку и замените адрес в `src="…"` в `02-hero.html` и `10-author.html` |
| Ссылки на Telegram / VK | `13-channel.html`, `14-footer.html` — адрес в `href="…"` |
| Цифры результатов | `06-results.html` |
| Пункты меню | `01-header.html` |
| Основной цвет | `00-styles.html` → в начале, `--pg-gold` |

- `<b>слово</b>` — слово выделяется жирным золотистым цветом.
- `<span class="pg-gold">слово</span>` — слово становится золотым градиентом.
- `<br>` — перенос строки.

Чтобы удалить ненужный раздел, просто удалите его блок в Tilda: остальные блоки от этого не сломаются (кроме 00-styles).
